# wrtn

A service for exchanging handwritten messages.

## Planned Features

- A Supernote plugin (see plans/supernote-plugin.md)
- A PWA to scan handwritten notes (see plans/scanner-pwa.md)

## Technical Philosophy

- Use existing protocols as much as practicable
- Typescript is the primary language
- Vitest for unit testing
- Use TPX for LLM features (see https://tokenpony.dev/llms.txt)
